# 🚀 Nova Studio

Una landing page moderna, elegante y completamente responsiva desarrollada con **HTML5** y **CSS3**. Este proyecto está diseñado como plantilla para empresas de tecnología, agencias digitales, startups o portafolios profesionales.

---

## 📸 Vista previa

La página incluye:

- ✨ Hero Section con imagen de fondo.
- 📱 Diseño Responsive.
- 🎨 Estilo moderno tipo Startup.
- 🚀 Tarjetas de servicios.
- 📊 Sección de estadísticas.
- 💬 Testimonios.
- 🌐 Footer con redes sociales.
- 🔥 Efectos Hover y Glassmorphism.
- 🎯 Código limpio y fácil de personalizar.

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio.

```bash
git clone https://github.com/tu-usuario/nova-studio.git
```

2. Ingresa a la carpeta del proyecto.

```bash
cd nova-studio
```

3. Abre el archivo **index.html** en tu navegador.

También puedes utilizar la extensión **Live Server** en Visual Studio Code para visualizar los cambios en tiempo real.
